# Cathiva Cervejaria — site estático

Arquivos prontos para publicação no GitHub Pages.

## Estrutura
- `index.html` — página principal
- `assets/` — logo e fotografias

## Publicação rápida no GitHub Pages
1. Crie um repositório, por exemplo `cathiva-site`.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório.
3. Em **Settings > Pages**, em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a URL gratuita do GitHub Pages ser publicada.

Não altere o DNS do domínio nem cancele o Wix antes de testar a página nessa URL gratuita.
